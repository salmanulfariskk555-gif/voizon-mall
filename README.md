# VOIZON Digital Solutions website

Static multi-page corporate website for GitHub Pages.

## Pages
Home, About, Services, Industries, Portfolio, Insights, Contact, Privacy and Terms.

## Publish
GitHub Pages → Settings → Pages → Deploy from a branch → select main and /(root).

## Before public launch
- Replace the text-based V logo with the approved official VOIZON logo asset.
- Add official company email and office address.
- Verify every service description and add only real portfolio items/testimonials.
- Complete privacy policy and terms based on actual business practices.
- Confirm the WhatsApp contact number.

The contact enquiry form opens a prefilled WhatsApp message; it does not silently store form data.
